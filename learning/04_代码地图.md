## 一、后端（Python）

### src/common/paths.py —— 路径解析

所有路径从 PROJECT_ROOT 派生，而 PROJECT_ROOT 由**本文件位置**反推（parents[2]）。
这样无论从哪个目录启动，路径都是对的——不依赖 cwd（IDE 里跑和命令行里跑结果一致）。

| 常量 | 指向 |
|---|---|
| WEB_DIR | web/ |
| RUNTIME_DIR / LOG_DIR / DATA_DIR | runtime/ 及其子目录 |

### src/data/codes.py —— 代码规范化

| 函数 | 作用 |
|---|---|
| normalize(code) | 任意格式 → 纯 6 位（sh600000 → 600000） |
| exchange_of(code) | 纯 6 位 → sh / sz / bj。**只服务个股，指数不适用** |
| to_market_code(code) | 纯 6 位 → sh600000（腾讯/新浪要的格式） |
| is_valid(code) | 不抛异常的合法判断 |

交易所规则表见文件开头的 docstring。**北交所 92 号段、上海 B 股 900xxx 是易错点。**

### src/heatmap/industry.py —— 申万行业映射（慢路径）

| 函数 | 作用 |
|---|---|
| build_map(...) | 拉行业树 + 逐个二级行业拉成分股 → Parquet。**约 50 秒** |
| load_map(auto_build, verbose) | 读缓存；不存在则按 auto_build 决定是否现场构建 |
| attach_industry(quotes, mapping) | 给行情表挂 l1_name / l2_name。**没归上行业的记为「未分类」** |

输出列：code, l1_code, l1_name, l2_code, l2_name（另有虚拟的「未分类」）。

### src/heatmap/universe.py —— 全市场代码表（慢路径）

stock_info_a_code_name → runtime/data/heatmap/universe.parquet，**5580 只**。

### src/heatmap/quotes.py —— 腾讯批量行情（快路径）

| 函数 | 作用 |
|---|---|
| fetch_quotes(codes, chunk_size=600, workers=8) | 分批并发拉全市场。**5580 只约 1.1 秒** |
| _parse_line(line) | 解析 v_sh600000="1~浦发银行~..."。**字段不足、停牌（现价 0）返回 None** |
| fetch_index_quotes() | 8 个指数（上证/深证/创业板/沪深300/科创50/中证500/中证1000/北证50） |

**单位换算就在这个文件里**（[37] 万元、[44]/[45] 亿元、[36] 手），改这里前先读 03。

### src/heatmap/treemap.py —— 云图组装

| 函数 | 作用 |
|---|---|
| build_treemap(quotes, metric, ...) | 组装嵌套树 + 汇总。**过滤 value <= 0**，板块按 value 降序 |
| _weighted_change(group, col) | 按列加权算涨跌幅（权重全 0 时回落算术平均） |
| _stock_node(row) | 单只票 → 叶子节点 |
| build_summary(df, index_quotes) | 顶部汇总 |

METRICS = {total_mcap, float_mcap, amount} 是面积口径白名单，加口径改这里。

### src/analysis/sector.py —— 板块强度（纯函数）

| 函数 | 作用 |
|---|---|
| compute_sector_strength(df, updated_at) | 全市场 + 一级 + 二级的强度指标。**纯函数**，不取数不落盘 |
| _aggregate(name, level, group, market) | 单板块聚合（03 里的每个字段都在这里） |
| append_snapshot(strength, now) | 一级行业快照追加到 JSONL，**每 5 分钟限流一条** |

### src/heatmap/service.py —— 后台刷新服务

| 方法 | 作用 |
|---|---|
| prepare() | 启动时加载行业映射 + 代码表（慢，只做一次） |
| refresh_once() | 拉行情 → 挂行业 → 组装云图 → 算板块强度 → 序列化 → 加锁写快照 |
| _loop() | 后台循环。**单次异常不会让线程退出** |
| treemap_json(metric) | 返回预序列化 bytes；切口径时用缓存行情**就地重算** |
| sector_json() / summary_json() / status() | 其余接口的 bytes |

### scripts/heatmap_server.py —— HTTP 服务

标准库 ThreadingHTTPServer，**零额外依赖**。

| 部分 | 说明 |
|---|---|
| _handle_api | /api/heatmap/* 与 /api/sector/* |
| _handle_static | 路由 /（云图）、/sector、/shared/、/data/ |
| _serve_file | 目录穿越防护 + 后缀白名单 |
| ALLOWED_SUFFIX | **加新资源类型要改这里** |

## 二、前端（JavaScript）

### web/heatmap/app.js —— 云图渲染（约 1100 行）

| 函数 | 作用 |
|---|---|
| buildLayout(tree, W, H) | **squarified treemap 算法**。必须沿矩形**短边**铺 |
| draw() | Canvas 绘制。个股方块 → 个股文字 → 板块标题带 |
| computeLabelPlan(t, scale) | 决定一个方块怎么写字的**纯计算**（结果按 scale 缓存） |
| fitFontSize(...) | 求能塞进方块的最大屏幕字号。**注意世界/屏幕单位换算** |
| setFontScreen(f, weight, scale) | 设屏幕字号（canvas 在 scale 变换下，内部要除以 scale） |
| clampView() | 把平移夹回「画布始终铺满」的范围。**四处调用** |
| hitTest / showTooltip / openQuote | 悬浮与点击（用 a 标签打开个股页） |
| fetchTreemap() | **后端优先，失败转 treeFromClient()** |
| showDetail(t) / scheduleDetail(t) | **悬停详情面板**（110ms 防抖） |
| drawKline(rows) | 日 K 蜡烛 + MA5/10/30 |
| renderDetailList() | 二级行业成分股列表（可排序） |
| openQuoteByCode(code) | 打开个股行情页（方块与列表共用） |
| applyTree(tree, ms) | 两条链路共用的界面应用逻辑 |

### web/sector/index.html —— 行业情况（单文件，内联 CSS/JS）

| 函数 | 作用 |
|---|---|
| fetchStrength() | **后端优先，失败转 loadClientSide()** |
| renderConclusion() | 用数据生成那句人话结论 |
| renderClock() | 每秒自己走；盘中/休市标识 |
| isTradingNow() | 交易日 9:30–11:30 / 13:00–15:00。**不判断节假日** |
| rsBar / bwBar | RS 双向条、宽度条 |

### web/shared/market.js —— 浏览器直连数据层（第二实现）

| 函数 | 对应 Python |
|---|---|
| exchangeOf / toMarketCode | src/data/codes.py |
| parseQuote | src/heatmap/quotes.py::_parse_line |
| loadScript | （新增）用 script 标签绕过同源策略 |
| fetchQuotes | fetch_quotes。分批 600 × 8 并发 |
| fetchIndexes | fetch_index_quotes |
| computeSectorStrength | src/analysis/sector.py |
| buildTreemap | src/heatmap/treemap.py::build_treemap |
| fetchAll | （新增）一次性拉全并缓存，供切口径复用 |
