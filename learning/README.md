# learning · 从零读懂这个项目

> 这个文件夹是**给人看的**，不是给程序看的。
> 目标：一个没接触过本项目的人，读完能自己跑起来、看懂每个数字、知道哪里会踩坑、敢动手改。

## 三句话版本

1. **大盘云图**：把全市场 5500+ 只股票按申万行业铺成 treemap，面积=规模、颜色=涨跌幅，一眼看清市场结构。
2. **行业情况**：一张板块强度榜，用 RS（相对大盘）、宽度、资金占比回答「哪个板块**真的**在动」。
3. **两个地方都能跑**：本地是 Python 后端（5 秒刷新、可落盘）；线上是 GitHub Pages，浏览器自己直连腾讯取数（10 秒刷新）。

## 一条忠告

这个项目**有两份实现**：Python 后端（`src/`）和浏览器端（`web/shared/market.js`）。
它们算的是同一套指标。**改任何一边的口径，另一边必须一起改**，否则线上线下会对不上。
细节见 [`05_注意事项.md`](05_注意事项.md) 的第一节。
